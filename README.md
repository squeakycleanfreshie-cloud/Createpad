
# Createpad
Createpad is a macropad for photoshoppers. I'm Following the hackpad tutorial.

**What contols does it do?**
Creatpad does the following shortcuts automatically:   
- move layer up/down shortcuts
- New layer shortcut

**Why did I create this?**   
Because I love photoshop, and I wanted to improve my hardware skills so I created this!

**Why does this help?**
This helps making move layers up and down way easier and seamlessly on photoshop and other adobe suite apps.

**How do you program it?**
Im using the QMK firmware project as firmware! You can find out how to port your keyboard here:
QMK Porting Guide: https://docs.qmk.fm/porting_your_keyboard_to_qmk
Configurator: https://docs.qmk.fm/newbs_building_firmware_configurator

**Assembly Instructions**
1. 3D print the case
2. solder the parts to the PCB
3. place the keycaps on and program it using the QMK firmware project
      - Make sure to make the top one: layer up (Cmd + J)
      - Middle one: new layer (Cmd+Shift+N)
      - Bottom one: Layer down (Cmd + [)
